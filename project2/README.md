# Project2 - GIF フレームビューア

ブラウザー上で GIF ファイルを読み込み、すべてのフレームを静止画として一覧表示するシンプルなアプリケーションです。

## 使い方

1. `index.html` をブラウザーで開きます。
2. 「GIF ファイルを選択」ボタンから任意の GIF 画像をアップロードします。
3. 読み込まれた GIF の全フレームがサムネイルとして表示され、各フレームの遅延時間も確認できます。

## 技術要素

- 純粋な HTML / CSS / JavaScript
- [gifuct-js](https://github.com/matt-way/gifuct-js) を使用して GIF ファイルを解析

インストール作業は不要で、静的ホスティングやローカルファイルとしてそのまま利用できます。
